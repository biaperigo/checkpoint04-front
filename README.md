EcoTrend — Checkpoint 04

Descrição do Projeto

O EcoTrend é um e-commerce especializado em produtos sustentáveis e ecológicos, focado em promover um estilo de vida mais consciente e sustentável. A plataforma oferece uma variedade de produtos que vão desde roupas e acessórios sustentáveis, passando por produtos de beleza e cuidados pessoais naturais, itens para casa sustentável, até tecnologia verde.
Este projeto foi desenvolvido para o Checkpoint 04 de Front-end Design, com o objetivo de criar uma interface responsiva e moderna utilizando HTML, CSS, CSS Grid e Bootstrap.

Páginas:

1. Página Inicial (index.html)
A página inicial apresenta um header com barra de navegação contendo a logo da EcoTrend, menu de navegação e ícone de carrinho de compras. O destaque é um carrossel implementado com Bootstrap que exibe promoções e produtos em destaque. Abaixo, há seções de produtos organizados em categorias (Roupas, Beleza, Casa, Tecnologia) utilizando o sistema de cartões do Bootstrap para uma apresentação visual atraente.

2. Página de Categorias (categorias.html)
Esta página exibe uma lista completa de produtos em um layout de grid responsivo. Cada produto é apresentado com sua imagem, nome, preço e botão "Adicionar ao Carrinho". Na lateral, há filtros implementados com colunas do Bootstrap.

3. Página de Detalhes do Produto (produto.html)
Quando o usuário seleciona um produto, é direcionado para a página de detalhes, que exibe informações completas do item. O layout apresenta a imagem do produto em destaque ao lado de informações detalhadas como descrição completa, preço, especificações técnicas e disponibilidade em estoque.

4. Página de Contato (contato.html)
A página de contato oferece um canal de comunicação entre a loja e os clientes. O formulário foi estilizado com Bootstrap e contém campos para nome, e-mail, assunto e mensagem, permitindo que os usuários entrem em contato facilmente para tirar dúvidas ou fazer solicitações.

5. Footer (presente em todas as paginas)
O rodapé do site contém informações importantes como links para redes sociais, informações de contato (e-mail e telefone) e políticas da loja (política de privacidade e termos de uso).
